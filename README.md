# docker-traefik-django
Развертывание проектов Django в контейнерах Docker под управлением Traefik.

Данный гайд нацелен на быстрое и безпроблемное развертывание Django приложений в docker контейнерах за обратным прокси Traefik.

## Аренда VPS/VDS
Для начала необходимо арендовать VPS/VDS сервер, в текущем гайде будет использоваться сервер на [хостинге FirstByte](https://firstbyte.ru/vps-vds/kvm-ssd/).

Для текущих задач будет достаточно конфигурации 2vCPU, 4Gb RAM 30 Gb SSD.
![Тариф на FirstByte](https://slink.shidron.ru/image/b3f11e4e-99f8-4152-b20b-bcd1fc467a5c.png)

После аренды сервера на почту придёт информация с логином, паролем от учетной записи root, а также IP-адрес сервера.
![Письмо с данными сервера](https://slink.shidron.ru/image/8afc9e8b-b246-4c60-9d38-1b9e14fae7dd.png)

## Настройка DNS-записей для домена
Также для работы нам понадобится доменное имя. Регистратора можно выбрать любого, который понравится. В текущем гайде будет показана работа с доменами у регистратора [СпринтНеймс](https://sprintnames.ru/).

После регистрации домена в панели управления необходимо настроить доменные записи. Всего нам необходимо настроить три DNS-записи.
![DNS-записи домена](https://slink.shidron.ru/image/c8ea1fa6-6380-4ad1-abd2-7dbf8ecafb7f.png)

Первая запись с полным указанием домена связывает наш корневой домен с конкретным IP адресом сервера.

Вторая запись определяет, что www.example-domain.ru - тоже относится к нашему серверу

Третья запись определяет, что все поддомены ведут на наш IP адрес.

Первые две записи - записи по умолчанию, должны быть везде. Третья запись создаётся для того, чтобы для поднимаемых контейнеров можно безпроблемно выделять поддоменны и трафик сразу будет перебрасываться на Traefik, который уже сможет отдавать контент конкретного контейнера.

## Работа с VPS

В данном гайде для работы по SSH будет использоваться клиент [Termius](https://termius.com/download/windows).

Для создания подключения необходимо нажать на "New Host" и указать IP адрес сервера, а также имя пользователя и пароль от учетной записи root. Данные указаны в письме от хостингера. После указания всех данных можно нажать на Connect, сохранить отпечаток и войти на сервер.
![Настройка подключения в Termius](https://slink.shidron.ru/image/d634376f-e10d-4c4c-b212-968c1f57fbd7.png)

После успешного входа на сервер, необходимо [установить Docker](https://github.com/shidron/docker-traefik-django/blob/main/docker.md).

После установки Docker необходимо выстроить иерархию папок для работы с контейнерами. 

Создаём папку в корневом каталоге и переходим в неё: `mkdir /docker && cd /docker`

В папке `docker` будут находиться папки для контейнеров с их compose файлами и данными.

Далее по порядку необходимо запустить контейнеры с [Traefik](https://github.com/shidron/docker-traefik-django/blob/main/traefik/traefik.md) и [Portainer](https://github.com/shidron/docker-traefik-django/blob/main/portainer/portainer.md)

На этом подготовка завершена, далее будем формировать контейнеры под Django-приложения и базы данных.
