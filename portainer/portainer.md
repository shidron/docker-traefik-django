# Запуск контейнера с Portainer

Таким же образом, как и запуск контейнера Traefik, создаём контейнер для [Portainer](https://www.portainer.io/).

После запуска контейнера переходим по URL адресу Portainer и видим следующее:
![Инициализация Portainer](https://slink.shidron.ru/image/61e343ab-cca4-4e7a-811f-ae14ed4bac9d.png)

Для поиска токена установки необходимо открыть логи контейнера командой `docker logs portainer`, где 'portainer' - название контейнера.
![Поиск токена установки в логах контейнера](https://slink.shidron.ru/image/e309b4ac-1965-45a9-bca5-3143b62220cf.png)

Данный токен необходимо выделить, после этого он окажется в буфере обмена (Ctrl + C не нужен) (Вставка из буфера обмена в консоль по ПКМ).
Далее пропускаем Edge и попадаем на главную страницу. Переходим по меню справа на Home и выбираем локальное окружение. 
![Инициализированный Portainer](https://slink.shidron.ru/image/746d5660-d382-46f1-a1ef-5bbf3fd70dda.png)
